# Fret & Fade

Guitar-finish inspired eyeshadow palette explorer.

## V1
Brand/model/finish selection, artistic eye preview, makeup sliders, photo overlay, PNG export and browser-local favourites.

## GitHub Pages
Go to Settings > Pages, select Deploy from a branch, choose `main` and `/ (root)`, then Save. Site URL should be `https://alfonsogordon.github.io/fret-and-fade-/` once GitHub finishes deploying. Pages availability for private repositories depends on the account plan. GitHub Pages websites are public even if source is private on standard plans.

The V1 preview is illustrative, not a photorealistic makeup simulator. Uploaded eye photos use a rough overlay without face landmark detection.
